# แพ็กข้อมูลเริ่มต้นสำหรับ Codex: 3D Lighting Show

โปรเจกต์นี้เป็น **ชุดข้อมูลและ Prompt สำหรับสร้างแอป** ไม่ใช่ตัวแอปสำเร็จรูป

## วิธีใช้
1. แตกไฟล์ ZIP แล้วนำโฟลเดอร์ทั้งหมดเข้าโปรเจกต์ Codex
2. เปิด `MASTER_PROMPT_CODEX_V2.md` แล้วส่งข้อความนี้ให้ Codex
3. ให้ Codex อ่าน `media/` + `config/` + `reports/` และทำ PHASE 0 ก่อน PHASE 1
4. ตรวจสอบพิกัดหน้างานจริงก่อนใช้อุปกรณ์ และตรวจผลการทดสอบทุก Phase

## ไฟล์สำคัญ
- `media/` ภาพสถานที่ 4 ภาพ + เสียงต้นฉบับ 10:12.101
- `config/venue_rig_editable_v2.json` รูปแบบเริ่มต้นไฟ 16 โคม NORTH ราว 8 + SOUTH เสาคู่ 4+4; **พิกัดตัวอย่าง**
- `config/theatrical_cues_seed.csv` คิวละครคร่าวๆ จากข้อมูลที่ผู้ใช้ให้ไว้ก่อนหน้า
- `config/dance_cue_proposals_NOT_FINAL.csv` แนวคิวเต้นจากความดังเสียงจริง ยังไม่ยืนยัน Verse/Chorus/Drop
- `reports/audio_analysis_summary.json` ผลตรวจไฟล์และประมาณ BPM เฉพาะช่วงเต้น
- `reports/audio_energy_overview.png` ภาพความเข้มเสียงพร้อมช่วงคิวจากรายการเดิม

## สิ่งที่ยืนยันจากข้อมูลได้
- เสียง AAC stereo, 44100 Hz, ระยะเวลา 612.101224 วินาที
- ภาพอ้างอิงมองเห็นอัฒจันทร์คู่ บันได จอ แป้นบาส และราวกันตก
- สัดส่วนสนามเริ่มต้น 28x15 เมตรตามแบบเดิม ไม่ใช่การวัดจริง

## สิ่งที่ยังต้องตรวจ
- ตำแหน่งที่ต้องการย้ายเสา/โคมจากแบบเดิม
- ขนาดอาคาร / ความสูงราว / จุดยึดโคมจริง
- รุ่นโคม, ช่อง DMX และช่วง pan/tilt ที่รองรับ
- พื้นที่นักแสดงเคลื่อนที่ ขอบเขตผู้ชมและจุดห้ามยิง
- จุดแบ่งท่อนเพลงและเวลาบทพูดตามไฟล์จริง
- สีส้มของคิวเก่า ต้องยืนยันว่าจะเปลี่ยนเป็นเหลืองตามพาเลตใหม่
- คิวจบเดิม 10:15 แต่เสียงยาว 10:12.101

ไฟล์ `venue_rig_editable_v2.json` เป็นข้อมูลวางแบบเพื่อจำลอง ไม่ใช่แบบวิศวกรรมติดตั้งโครงสร้างจริง
